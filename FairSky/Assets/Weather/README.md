# Outlined weather icons

Original FairSky artwork, covered by the repository MIT license.
SVG files are editable sources (32-unit view box). PNG files are transparent
96 × 96 exports used at small sizes by Command Palette and MarkdownContent.
All runtime images are local package content. Dark contours stay visible on
light backgrounds; a narrow white outer line separates them from dark backgrounds.
Do not replace these with font emoji, whose colors and contrast depend on the OS.

After editing an SVG, regenerate its corresponding 96 × 96 transparent PNG
with an SVG renderer such as Sharp, and inspect at 16/20/32 px on both themes.
