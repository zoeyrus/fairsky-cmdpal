# Contributing to FairSky

Thanks for helping make weather information accessible in Command Palette.

1. Open an issue before proposing a major redesign.
2. For fixes, create a focused branch and explain what changed.
3. Do not commit secrets, signing certificates or private user configuration.
4. Preserve third-party licensing and MET Norway attribution.
5. Test the Command Palette page **and** Dock behavior on Windows. Include the SDK version and build output in bug reports.
6. Keep user-facing strings ready for localization rather than adding more hard-coded language text.

This is an early-stage project. Please be considerate of other contributors.
